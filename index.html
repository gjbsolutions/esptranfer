Encryption (both sides must use the same key)

No key set — traffic is sent unencrypted.
AES-256-GCM, key from PBKDF2-SHA256 (600k iterations). Packet header is authenticated (AAD). IVs are 64-bit random session id + 32-bit counter; receivers keep a 128-packet replay window per sender. A new peer session must answer a fresh challenge before any of its packets are accepted. Use Generate for a random 160-bit key (copy it before Set key) — a human-chosen passphrase can be brute-forced offline.
